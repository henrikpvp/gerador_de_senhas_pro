## Gerador de senhas Pro

Um gerador de senhas moderno, seguro e com interface gráfica, desenvolvido em Python.

## Funcionalidades
- Interface moderna (Dark Mode nativo).
- Geração de senhas seguras usando a biblioteca `secrets`.
- Ajuste de tamanho de senha via slider (8 a 32 caracteres).
- Botão "Copiar" automático para a área de transferência.

## Tecnologias Utilizadas
- **Python 3.x**
- **CustomTkinter**: Para a interface visual moderna.
- **Pyperclip**: Para a função de copiar.
- **Secrets**: Para garantir aleatoriedade criptográfica.
